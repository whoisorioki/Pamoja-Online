# Nguvu Pamoja Online Platform

A companion website for Nguvu Pamoja, a Fountwood Community Support Program
that meets in person every Friday. This site extends that session to
participants who are online and can't attend in person — the week's
curriculum, a video room, a check-in ritual, private journaling, and a
gender-separated forum.

Full context, decisions, and design constraints: `nguvu-pamoja-sot.md` and
`nguvu-pamoja-implementation-plan.md`. Agent-facing conventions: `AGENTS.md`.

## Setup

```
npm install
npx @11ty/eleventy --serve
```
